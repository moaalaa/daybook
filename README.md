# Daybook

A todo app with a profile page. Plain static HTML (Tailwind CSS v4, daisyUI 5,
Font Awesome) with **one JavaScript file** for behavior. No sidebar, no
categories. Data is saved to the browser's localStorage.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Pages

- **`index.html`** (home page) — the todo list. Search box sits on the page
  itself, under the heading, not in the header. Add / edit / delete / check off
  todos, with filters (All / Active / Done) and a progress bar.
- **`profile.html`** — a form to edit username, email and password for the
  logged-in user. No sidebar.

Both pages share the same simple header: the Daybook logo on the left, and on
the right either a **Log in** button or (once logged in) your avatar + name,
linking to the profile page, with a logout button next to it.

## How it's built

- Every todo, form, and modal is written directly in the HTML — view-source
  shows the same markup you'd write by hand, nothing is generated by JS.
- **`src/app.js`** is the only script. It doesn't build page layout from
  strings — it reads/writes attributes and text on elements that already
  exist, and opens/closes daisyUI's native `<dialog>` modals with
  `.showModal()` / `.close()`.
- Modals (`#login_modal`, `#todo_modal`, `#confirm_modal`) are plain
  `<dialog class="modal">` elements already sitting in the HTML. Because each
  has an `id`, the browser exposes it as a global automatically, so
  `onclick="todo_modal.showModal()"` works directly from markup — that's
  daisyUI's own documented pattern, nothing custom.
- Login is a demo: entering an email/password in the header's login modal
  either logs into the one saved account (if the email matches) or creates
  one on the spot. There's no real backend.

## Where to look

| File | What it does |
|---|---|
| `index.html` | Home page: todos + search box + add/edit/delete, login modal |
| `profile.html` | Username/email/password form, login modal |
| `src/app.js` | All behavior: todos CRUD, search, filters, login/logout, profile save |
| `src/style.css` | Theme colors, fonts |

## Tweak the look

Open `src/style.css`. Change `--color-primary` or `--color-neutral` and the
whole app follows.

## Reset the demo data

Browser console: `localStorage.clear()` then refresh.
